# askmd

`.md` だけに絞った軽量ビューア。ディレクトリツリーから素早く開いて読み、選択した箇所をそのまま Claude に質問できる。

## 位置づけ

- 対象: Claude Code ユーザー（手元に `claude` CLI がある前提）
- コンセプト: 「docs を溜め込んでいる人が、サクサク回遊して、気になった箇所をその場で聞ける」
- 非目的: Markdown の編集、ノート管理、WYSIWYG

## ステータス

Phase 1 (MVP) 実装中。

## ドキュメント

- [docs/CONCEPT.md](docs/CONCEPT.md) — プロジェクトの背景・設計思想・既存ツール比較・意思決定の記録
- [CLAUDE.md](CLAUDE.md) — コード規約 / AI 協働ノート
